# Allin Denim Image Prompt Plan

Use these prompts to generate preview visuals before replacing them with real factory, product, team, certification, client reference, and case study assets.

Guidelines:

- Use realistic premium B2B photography.
- Do not include fake client logos, fake certifications, readable text, watermarks, or brand names inside images.
- Prefer WebP or JPG for final web usage.
- Use vertical 4:5 for hero/category images.
- Use horizontal 3:2 for section/support images.
- Save generated previews under `public/assets/images/preview/` with the suggested filenames.
